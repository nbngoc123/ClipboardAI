## ✨ Features

- **🚀 PowerToys-Inspired Design:** A sleek, dark-themed, and responsive UI blending perfectly with Windows 11 aesthetics.
- **⚡ Quick Access Popup:** Press `Ctrl+Shift+V` anywhere to bring up your clipboard history instantly.
- **🖼️ Image Support:** Seamlessly copies and pastes both text and images.
- **📦 Batch Copy Mode:** Toggle `Ctrl+Shift+B` to enter Batch Mode. Copy multiple items sequentially, and paste them all at once!
- **🗑️ Self-Destruct / Danger Zone:** A one-click "Wipe Data" feature to securely erase all your local clipboard database and image files and uninstall the app cleanly.
- **💻 Portable (Single File):** Distributed as a single `ClipboardAI.exe` executable. No installation required!

## 📥 Download & Usage

1. Go to the [Releases](https://github.com/nbngoc123/ClipboardAI/releases) page.
2. Download the latest `ClipboardAI.exe`.
3. Double click the file to run. 
4. The app will quietly sit in your System Tray. Double click the tray icon to open the **Dashboard/Settings**.
5. Press `Ctrl + Shift + V` to open the Clipboard History popup.
